# QI-NFTL: Quantum-Inspired Neuro-Fuzzy Temporal Learning

This repository contains the official implementation of the **QI-NFTL** framework for uncertainty-aware time series forecasting.

## Abstract
The QI-NFTL framework addresses the curse of dimensionality in neuro-fuzzy systems by utilizing quantum-inspired superposition for parallel rule evaluation.

## Repository Structure
- `data/`: Contains pre-processed benchmark datasets (Finance, Energy, Weather).
- `src/`: Core implementation of the quantum-inspired encoding and hybrid learning.
- `requirements.txt`: Python dependencies required to run the model.
